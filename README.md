# 更懒的体验

一个面向 tModLoader 1.4.4 的 Terraria 综合型便利/扩展 Mod，目标是在不改变游戏核心体验的前提下，提供更方便的礼包、建造、事件、召唤与功能性物品。

## 功能概览

### 1. 礼包系统

提供多种开局、Boss、进度与功能礼包，并支持额外 Mod 联动。

当前项目包含：

- 原版相关礼包
- 多种药水/功能类礼包
- Calamity 联动礼包
- Magic Storage 联动代码
- Fargo's Souls 相关整合代码
- 礼包内容注册与覆盖机制

礼包系统通过统一注册表管理，并支持其他 Mod 调用接口获取礼包信息或修改礼包内容。

### 2. 平台建造器

提供可配置的平台快速建造工具，支持：

- 平台长度调整
- 建造方向调整
- 不同平台形状
- 平台间隔灯光放置
- 建造前预览
- 建造历史记录
- 撤销上一次建造
- 每名玩家独立保存平台/灯光选择

玩家的建造器配置会保存到角色数据中，并在进入世界时恢复，无需先打开建造器 UI。

> 注意：多人联机下的世界修改仍建议谨慎使用，当前版本更适合单人游戏或充分测试后的联机环境。

### 3. 异变事件：异界狂雨

使用 **恐怖气球** 开启异界狂雨事件。

事件期间：

- 天空进入异常暴雨状态
- 风力增强
- 出现特殊视觉效果
- 随机生成危险物与事件敌怪
- 肉后阶段会使用独立的肉后怪物池
- 事件敌怪会计入事件击杀进度
- 达到 **180 次事件击杀** 后完成事件
- 根据当前进度阶段发放对应奖励

事件状态属于当前世界，并在进入/离开世界时正确初始化与清理。

### 4. 灵魂驯服系统

通过灵魂相关物品与契约机制驯服 NPC，并支持：

- 解锁可驯服 NPC
- 灵魂标记
- 契约束缚
- 驯服 NPC 数量管理
- 相同 NPC 的数量限制
- NPC 召唤与跟随

### 5. 功能性物品

项目还包含多种功能型物品与特殊机制，例如：

- 黑洞石
- C-Moon 药水
- 空间移动药水
- 小国王药水
- 竹蝉相关装备/效果
- 蛇形手镯相关攻击机制
- 多种特殊武器与投射物

具体功能以游戏内物品说明和当前版本代码为准。

## 安装

1. 安装 tModLoader 1.4.4。
2. 下载本 Mod 的源码或编译后的 Mod 文件。
3. 将 Mod 放入 tModLoader 对应的 Mod 目录。
4. 启用 **更懒的体验**。
5. 根据需要启用 Calamity、Fargo's Souls、Magic Storage 等联动 Mod。

## 开发说明

### 世界状态与玩家状态

项目中的状态数据应根据生命周期分为：

- **世界状态**：当前世界有效，进入世界时初始化，离开世界时清理。
- **玩家状态**：绑定角色，通过 `ModPlayer` 保存与读取。
- **Mod 全局状态**：只保存真正属于 Mod 生命周期的数据，例如已经建立的内容注册表或静态资源信息。

新增功能时应尽量避免使用无生命周期控制的 `static` 变量保存玩家或世界状态。

### 联机开发

涉及以下功能时，应优先保证服务器权威：

- NPC 生成/击杀
- Projectile 生成
- 玩家传送
- 世界 Tile 修改
- 事件进度
- 奖励发放

客户端主要负责 UI 与视觉表现，世界实际状态尽量由服务器决定并同步。

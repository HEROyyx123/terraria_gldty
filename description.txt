1. 礼包系统

提供多种开局、Boss、进度与功能礼包，并支持额外 Mod 联动。

当前包含：

- 原版相关礼包
- 多种药水/功能类礼包
- Calamity 联动礼包
- Magic Storage 联动礼包
- Fargo's Souls 相关整合物品

2. 平台建造器

提供可配置的平台快速建造工具，支持：

- 平台长度调整
- 建造方向调整
- 不同平台形状
- 平台间隔灯光放置
- 建造前预览
- 建造历史记录
- 撤销上一次建造
- 每名玩家独立保存平台/灯光选择

玩家的建造器配置会保存到角色数据中，并在进入世界时恢复，无需先打开建造器 UI。

> 注意：多人联机下的世界修改仍建议谨慎使用，当前版本更适合单人游戏或充分测试后的联机环境。

3. 异变事件：异界狂雨

使用 **恐怖气球** 开启异界狂雨事件。

事件期间：

- 天空进入异常暴雨状态
- 风力增强
- 出现特殊视觉效果
- 随机生成危险物与事件敌怪
- 肉后阶段会使用独立的肉后怪物池
- 事件敌怪会计入事件击杀进度
- 达到 **180 次事件击杀** 后完成事件
- 根据当前进度阶段发放对应奖励


4. 灵魂驯服系统

通过灵魂相关物品与契约机制驯服 怪物，并支持：

- 解锁可驯服 怪物
- 灵魂标记
- 契约束缚
- 驯服 怪物 数量管理
- 相同 怪物 的数量限制
- 怪物 召唤与跟随
